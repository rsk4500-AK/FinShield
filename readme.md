\# FinShield Setup Guide



\## 1. Install dependencies



```bash

npm install

```



\## 2. Create a `.env` file



```env

VITE\_API\_KEY=YOUR\_NVIDIA\_API\_KEY



MONGODB\_URI=YOUR\_MONGODB\_URI



MONGODB\_DB\_NAME=FinShield



MONGODB\_COLLECTION=records

```



\## 3. Start the backend



```bash

npm run dev:server

```



\## 4. Start the frontend



```bash

npm run dev

```



\## 5. Open



```

http://localhost:5173

```



(or the port shown by Vite)
